Applicable only when task evidence includes document/image inputs.

Check:
- supported file types and size/page limits
- text vs image/scanned pages
- ordering/layout/table semantics
- encoding/language
- extraction confidence and unparsed regions
- deterministic output schema
- malformed/encrypted/empty documents
- whether OCR is actually required
- privacy/external-transmission restrictions

For this exam, do not use Computer Use or send documents to external services.
