# EXAM POLICY — SK hynix AI Hackathon 2nd Preliminary

This file is the highest-priority policy in this starter kit.
If the actual exam UI, official guide, Cofa Helper, or task-specific instructions conflict with this file, the **newer official exam/task instruction wins**.

## Confirmed from the official brief

- Task solving: **maximum 180 minutes**.
- Follow-up written test: **6 questions × 5 minutes = 30 minutes**.
- Follow-up is completed **without AI** and **without copy/paste**.
- Recommended provided models: **Sol 6.1, Terra 5.6, Luna 6, Sol 6.0**.
- **Astra is restricted.**
- **Claude Code and separately connected AI models are not allowed.**
- **Problem files and results must not be transmitted/shared externally.**
- **Git Push is prohibited.**
- **Computer Use / automated UI control is prohibited at every stage.**
- Public **AI Skills, MCPs, Plugins, and public GitHub tools may be downloaded/used**, but all other restrictions still apply.
- External source code/reference algorithms may be partially reused, but must not replace the submission wholesale.
- Use **Cofa Helper** for exam UI/submission questions and official incident reporting for repeated technical errors.

## Starter-kit rules derived from the brief

1. Downloading this public repository is allowed; **never push task work back to it during the exam**.
2. This kit must never send task data to external services.
3. Browser/UI automation is disabled for this exam, even if a tool technically supports it.
4. Final explanation practice is mandatory before submission because the follow-up cannot use AI.
5. Model names are recommendations, not proof of actual runtime selection. Verify the actual available model in the provided Codex UI/CLI.
6. Task-specific rules and grading contracts always override generic playbooks.
