# r7.2 full-source review

Scope: the fixed SK hynix exam format with an unknown task domain. This does not
certify arbitrary software tasks, missing runtimes, inaccessible endpoints, human
memory or all hidden grading conditions. EXAM_POLICY.md remains byte-for-byte
unchanged. The earlier composite mock used r7.1, not this revision.

## Review and executed scope

- All 89 files in the original r7.2 distribution were assigned for complete source
  review across policy/roles, domains, runtime/data/scoring and lifecycle/package.
- The corrected Linux/Python 3.12 suite ran 155 tests in 17.794 seconds: 154 passed,
  one PowerShell-executable check skipped. The package integration actually installs,

- A separate reviewer replays concrete counterexamples against corrected files.
  Cross-platform release results belong to the exact commit's PR checks; local
  grammar parsing alone is not Windows or Python 3.8 runtime evidence.

## Reproduced boundaries and corrections

| Severity | Boundary | Correction |
|---|---|---|
| P2 | Newline in an external-source installation target injected unrelated Git ignore rules | Reject target control characters before writes |
| P2 | FIFO manifest/legacy/support metadata could block install, doctor or cleanup | Descriptor-checked regular reads, bounded metadata and streamed support copies |
| P2 | Invalid Git exclusion destination caused a failed partial installation | Inspect/read the destination before helper writes |
| P3 | A package missing a mandatory core skill could still be produced | Validate all core skills and required support before packaging |
| P2 | FIFO evidence could block gate/preflight/hash commands | Bounded non-symlink regular-record reads for all gate inputs |
| P2 | JSON float rounding collapsed distinct exact values/rows | Exact decimal parsing plus typed nested fingerprints; scale statistics remain approximate |
| P2 | Inventory lexical normalization changed a parent-symlink/`..` lookup target | Preserve the returned path's actual filesystem meaning |
| P2 | Deep small package metadata crashed the entire inventory | Per-manifest recursion handling with an unreadable notice |
| P3 | Escaped surrogate metadata crashed inventory UTF-8 rendering | Escape unencodable output without changing originals |
| P3 | Chunk boundaries distorted failure-log triage | Bounded pending tokens and physical-line anchoring |
| P3 | CP1 template's three-finding wording omitted the canonical blocker exception | State three non-blocking findings plus every blocker |

These are concrete corrections, not evidence that ordinary operation always failed.
The current complete archive already contained the required core skill in the
incomplete-source packaging counterexample. Log triage remains heuristic; native
framework output and exit semantics are authoritative.

## Applicability and limits

Keep original task requirements/tools, supported formats, exact contracts and the
newer official clock. Activate only evidenced domain lenses. Provided task-internal
LLMs may be used when explicitly authorized; a separate provider may not be added.
Source/build/API checks do not establish rendered human UI verification. Missing
required OCR/compiler/endpoint access remains a blocker or labeled partial result.

Local coverage compares only declared evidenced checks under unchanged rules,
checker hashes and known data/policy/options scope. It neither authenticates supplied
observations nor discovers hidden official weights. A maximum does not waive P0/P1.
The five-document gate does not automatically freeze arbitrary external evaluator
files; original evidence and independent review remain required.

The workflow is protocol-based role separation on a shared environment, not an OS
sandbox or guarantee against all filesystem races. Full data in every task format,
arbitrary mutation combinations and unavailable real-exam services were not tested.
