# Task type routing

| Type | Typical signals | Add these skills |
|---|---|---|
| Data analysis / anomaly | CSV/JSON/XLSX, aggregation, detection | data-profiler, verification |
| Optimization / assignment | routing, schedule, allocation, capacity | optimization, constraint-discovery |
| Web app / CRUD | forms, login, dashboard, persistence | web-app, verification |
| API integration | endpoint, token, request/response | api-integration, debugging |
| Agent / chatbot / RAG | model, tools, retrieval, chat history | agent-chatbot, api-integration |
| Debugging | broken existing app, failing tests | debugging, verification |
| Automation | cron, queue, workflow, recurring task | automation, verification |
| Mixed | several of the above | choose only relevant playbooks |

Do not force a task into one type. Mixed is valid.
