# EDGE CASES

| Edge case / boundary | Why difficult or dangerous | Prevented / observed | Test / check | Result / UNVERIFIED | Time / code version | Original evidence |
|---|---|---|---|---|---|---|

A prevented edge case is valid even if it never became a production bug.
Do not invent cases unsupported by the task or implementation.
Reading code alone is not a passing runtime check. Identify automated checks and participant-performed checks separately.
