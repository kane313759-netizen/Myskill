# 데이터 감사 기록

`data_audit.py` 출력 JSON을 이 문서의 유일한 JSON 블록으로 보존하거나 별도 JSON 기록을 참조한다. 제공된 파일만 검사한다. 원시 민감값을 복사하지 않고 경로·SHA256·검사 행 수·최대 바이트·샘플 한계를 남긴다. `RECORDED`는 관찰 기록이며 업무적으로 안전하다는 인증이 아니다. 자동 확인이 불가능한 항목은 `UNVERIFIED`로 유지하고 독립 DATA_EVAL_RED가 실제 증거를 검토한다.

| ID | 검사 | 확인 방법·발견·조치 또는 N/A 전제 |
|---|---|---|
| 1 | 시각 역행·지연·시간대 | 미검증. 시간처럼 보이는 컬럼이 있으면 N/A 불가 |
| 2 | 단위·스케일 변화 | 미검증 |
| 3 | 코드·정의 개정 | 미검증 |
| 4 | ID·조인 행 폭증 | 미검증 |
| 5 | 결과 누수 | 미검증 |
| 6 | 표본 편향 | 미검증 |
| 7 | 교란 변수 | 미검증 |
| 8 | 분포 이동 | 미검증 |
| 9 | 폐기 문서·위험 지시문 | 미검증 |
| 10 | 결측·이상값의 원인 | 미검증 |

표 데이터가 없는 문서 과제는 해당 전제가 확인된 항목만 N/A 가능하다. 빈 파일·일부 표본·읽기 실패를 전체 데이터 확인으로 바꾸지 않는다. 이 기록의 경로와 현재 SHA256을 SPEC_DRAFT 검증 계획에 함께 적어 CP1 독립 리뷰에 포함한다. N/A 목록은 학습 시간에 보여 주며 참가자 확인을 작업 선행 조건으로 삼지 않는다.
